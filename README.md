# Calcwork

A browser-based calculator for everyday, scientific, programming, conversion, and business calculations. Calculations run locally in your browser.

## Features

- Standard and scientific calculations with degree and radian modes
- Programmer mode with binary, octal, decimal, hexadecimal, and bitwise operations
- Unit conversions for length, mass, temperature, area, volume, speed, time, and data
- Business calculators for percentages, discounts, tax, margins, loans, tips, dates, and age
- Formula library and function graphing
- Calculation history, memory controls, keyboard input, and theme toggle

## Run locally

Open `index.html` in a browser. No installation or build step is required.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

GitHub Pages is free for public repositories on GitHub Free. The published URL will appear in the Pages settings.
